# Holistika — медия за публикуване

Публично хранилище с **една-единствена задача**: да сервира одобрените визии
на публичен HTTPS адрес, защото Instagram Graph API не приема файл, а линк —
сървърите на Meta сами теглят снимката (`image_url`).

Адрес: **https://frivolous-b.github.io/holistika-media/**

```
2026-08-31/
    01.jpg … 10.jpg      визиите, JPEG 1080×1350 (единственият формат, който Meta приема)
    index.json           номер, заглавие, публичен адрес и надпис на всяка
index.html               галерия за преглед
base_url.txt             адресът на GitHub Pages — оттам скриптовете градят линковете
```

Файловете тук се слагат от `bot/stage_media.py` в работното хранилище на проекта.
Тук няма нищо тайно: това са картинките, които така или иначе излизат в Instagram.
Брифът, текстовете, каталогът и решенията по проекта са в отделно **частно** хранилище.

## Как се обновява

```bash
# в работното хранилище
cd bot
python3 prepare_media.py queue/<партида>     # PNG → JPEG
python3 stage_media.py  queue/<партида>      # копира тук + обновява галерията

# тук
git add -A && git commit -m "партида <дата>" && git push
```

GitHub Pages строи около минута след push. Чак тогава линковете са живи.
